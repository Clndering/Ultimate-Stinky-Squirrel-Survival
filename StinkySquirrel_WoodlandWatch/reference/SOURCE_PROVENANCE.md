# Original project record

Woodland Watch was built from the `StinkySquirrel_Godot47_FinalReview` directory in [Ultimate Stinky Squirrel Survival commit 05cd3e9](https://github.com/Clndering/Ultimate-Stinky-Squirrel-Survival/commit/05cd3e98bbf8a5a784131df7d5338fc3e873b32a). The original game's source files are preserved in that repository.

The two HTML files differ. Both embed 27 original sprites and six WAV files that match the corresponding files in Woodland Watch byte for byte. The full desktop asset comparison found identical files for 89 PNGs under `art/`, 33 PNGs under `ui/`, seven audio files, and one shader. These checks compare source bytes. The two browser builds have their own gameplay and networking implementations.

The original [desktop README](legacy/README_NIGHTWATCH_DESKTOP.md) and [desktop development notes](legacy/AGENTS_NIGHTWATCH_DESKTOP.md) are archived here. The other original desktop review files and patch notes remain in the project root for historical reference.
