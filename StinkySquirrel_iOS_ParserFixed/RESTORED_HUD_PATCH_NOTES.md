# Stinky Squirrel: Nightwatch — Glow HUD & Upgrade Cards Update

Target: **Godot 4.7**, GDScript, native Compatibility renderer. Based directly on the previous **Glow UI & Combat Fix** project.

## Visual / UI changes

- **Bottom-left dash cooldown:** a compact circular cooldown gauge shows the seconds remaining to one decimal place, the refill ring, and `SPACE` below it. The ring turns teal when ready.
- **Health bar:** restores a native gradient from pale gold to coral with a light glow, tick border, and original HP readout.
- **Ammo meter:** replaces the number-only display with individual glowing ammo ticks, arranged in up to 14 columns and automatically supporting all six weapons. Number remains only as a small secondary readout.
- **HTML-style upgrade picker:** three large side-by-side rarity-framed cards, colored rarity headings, individual descriptions and a large selection button. Keyboard keys `1`, `2`, `3` and numpad digits work, even when a GUI control has focus.
- **Armory gun previews:** nineteen actual 106×58 transparent pixel-art sprites generated by executing the geometric paint instructions from the previous HTML gun skins (not simply recolored rectangles), including shape and attachment variations. Those same images render on characters' guns in the native world. No changes to character sprites.
- Existing rarity-icon upgrade history, wardrobes, encyclopedia, main-menu artwork, settings and browser-save import are retained.

## Lag-spike investigations / improvements

1. **Frequent disk writes:** Previously the game serialized and wrote the native save JSON on every enemy kill, boss kill, acorn pickup and unlock. `_save_progress()` now marks the save dirty; `_flush_progress()` persists data at most once per 2.8 seconds during play, at upgrades/end of run, when returning to the menu, and on window close.
2. **Hit-particle bursts:** visual particle effects are capped at 320 active particles; transient shot traces at 180. Damage, collision, loot and combat stats are unchanged.
3. **HUD layout churn:** the HUD text is only assigned when changed. Meters only redraw when their display values change; the HUD is refreshed about 15 times per second instead of at every frame.
4. No new full-screen shader passes, navigation meshes, new polling threads or post-processing effects were added.

These changes address *likely* causes of frame-time spikes, not a proven benchmark result. Test on the same PC that previously maintained ~100 FPS.

## Multiplayer

The five multiplayer RPC handlers and existing ENet six-player networking code are retained. Shared upgrade picks are still host authoritative; guests remain spectators at host upgrade selection as in the previous version. Cross-device LAN remains untested in this environment.

## Installation and testing

1. Extract the ZIP into a **new folder** (do not merge with the old project).
2. In the Godot **4.7** project manager, Import `project.godot` in the new folder.
3. Press **F5**. Confirm the dash circle (bottom left), glowing HP (top left), tick ammo (top right), and 1/2/3 cards after the first wave.
4. Open Main Menu → Armory, select each weapon, and compare the skin preview to the native gun model.
5. Keep native graphics effects OFF to baseline-test FPS, then turn them on individually if desired.

**Testing status:** 27 original art assets and 6 WAVs remain exact matches; 19 skin images were checked to be distinct, and the project's static asset/code checks pass. There is no Godot 4.7 executable in this environment, so successful compilation, on-device FPS, and physical six-player LAN performance have *not* been independently verified. Your existing save file remains `user://stinky_squirrel_native_save.json`.
